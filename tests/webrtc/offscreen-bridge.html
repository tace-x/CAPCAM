Boundary bridge experiment

This isolated Chrome test page uses the existing typed runtime protocol for media ingestion and stream lifecycle. A separate, versioned BroadcastChannel probe—compiled only in build:camera-test—asks the offscreen document to structured-clone its actual active stream to this extension page. This page then uses native window.postMessage to send it to a localhost consumer tab.

Test-only: no website injection, content script, site adapter, permission bypass, or production bridge is installed. Load the camera-test build only when running this experiment. The normal npm run build excludes the offscreen BroadcastChannel listener.
